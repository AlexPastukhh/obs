ASP.NET CORE HTTPREQUEST (incoming request)

KEY PROPERTIES
- Body (Stream) -> raw request body stream (read bytes/text manually)
- BodyReader (PipeReader) -> high-performance pipeline reader for request body
- ContentLength (long?) -> value of Content-Length header
- ContentType (string?) -> value of Content-Type header
- Cookies (IRequestCookieCollection) -> cookies sent by client
- Form (IFormCollection) -> parsed form fields (form-urlencoded/multipart)
- HasFormContentType (bool) -> true if request body is form data
- Headers (IHeaderDictionary) -> all request headers
- Host (HostString) -> host header (can include port)
- HttpContext (HttpContext) -> parent context for current request
- IsHttps (bool) -> true if request uses HTTPS
- Method (string) -> HTTP method (GET/POST/PUT/PATCH/etc.)
- Path (PathString) -> URL path (without query string)
- PathBase (PathString) -> app base path (if hosted under subpath)
- Protocol (string) -> HTTP version (HTTP/1.1, HTTP/2, HTTP/3)
- Query (IQueryCollection) -> parsed query parameters
- QueryString (QueryString) -> raw query string (e.g. ?page=1)
- RouteValues (RouteValueDictionary) -> route params matched by endpoint
- Scheme (string) -> "http" or "https"

KEY METHODS
- ReadFormAsync(...) -> reads/parses request form body asynchronously


ASP.NET CORE HTTPRESPONSE (outgoing response)

KEY PROPERTIES
- Body (Stream) -> raw response body stream (write bytes/text manually)
- BodyWriter (PipeWriter) -> high-performance pipeline writer for response
- ContentLength (long?) -> value for Content-Length response header
- ContentType (string?) -> response Content-Type header
- Cookies (IResponseCookies) -> append/delete cookies to send to client
- HasStarted (bool) -> true if response headers were already sent
- Headers (IHeaderDictionary) -> response headers collection
- HttpContext (HttpContext) -> parent context for current request/response
- StatusCode (int) -> HTTP response status code (200, 404, 500, etc.)

KEY METHODS
- OnStarting(...) -> callback before headers are sent (last chance to change)
- OnCompleted(...) -> callback after response is finished
- StartAsync(...) -> starts response (headers become committed)
- CompleteAsync(...) -> completes/flushed response
- Redirect(...) -> sends redirect response (301/302/etc.)
- RegisterForDispose(...) -> dispose object automatically after response ends
- RegisterForDisposeAsync(...) -> async dispose object after response ends

COMMON RESPONSE EXTENSION METHODS (very useful)
- WriteAsync(...) -> write text to response body
- WriteAsJsonAsync(...) -> serialize object as JSON and write response
- Clear() -> clear headers/body/status (only before response starts) ^VEW9FgUU
