Как автоматически получить токен:
Шаг 1: Получите данные приложения
Откройте: 
https://vk.com/apps?act=manage
Выберите ваше приложение (или создайте новое)
В настройках найдите:
ID приложения (Application ID / Client ID) - например 51234567
Защищённый ключ (Secure key / Client Secret) - длинная строка типа AbCdEf123456
Шаг 2: Установите данные в Postman
Откройте коллекцию 
VK API Testing
Перейдите на вкладку Variables
Заполните:
client_id → вставьте ваш App ID
client_secret → вставьте ваш Secret Key
Нажмите Save (Ctrl+S)
Шаг 3: Получите код авторизации
Замените YOUR_APP_ID на ваш реальный ID и откройте в браузере:

Авторизуйтесь и разрешите доступ

После редиректа URL будет выглядеть так:

Скопируйте значение code (всё после code=)

Шаг 4: Получите токен автоматически
Вернитесь в Postman
Откройте вкладку Variables коллекции
Вставьте скопированный код в переменную auth_code
Сохраните (Ctrl+S)
Откройте запрос "0. Get Access Token (Authorization Code Flow)"
Нажмите Send
✅ Токен автоматически сохранится в переменную vk_token!

Шаг 5: Запустите все тесты
Теперь можете запустить всю коллекцию через Collection Runner:

Откройте коллекцию
Нажмите Run
Убедитесь, что выбраны все запросы (включая "0. Get Access Token")
Нажмите Run VK API Testing
⚠️ Важно:
Код авторизации одноразовый - после использования нужно получать новый
Код истекает быстро (обычно через 1 час)
Токен действует дольше (обычно 24 часа)
Храните client_secret в секрете - не делитесь им!
🔄 Для повторного использования:
Когда токен истечёт, просто:

Получите новый code через браузер (Шаг 3)
Обновите переменную auth_code
Запустите запрос "0. Get Access Token"
Готово! Теперь у вас есть автоматизированный процесс получения токена. Попробуйте и дайте знать, если возникнут вопросы! 🎉
