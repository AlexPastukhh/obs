# R-AI-1 — Promote AI System Content Into Typed Repetition Owners

Status: replacement package created  
Branch target: `ai-conspects-repetition-plan`

## Scope

This package promotes useful content from `AI System/Conspects Repetition/` into active typed `-Repetition/` owner files.

It does **not** delete or modify the old `AI System/Conspects Repetition/` folder.

## Included changes

- Adds active principles/profile/workflow/template owners under `-Repetition/`.
- Updates navigation/routing/responsibility map.
- Updates existing workflows to depend on the new owner files.
- Updates `Documentation Architecture Adapter.md` to reflect that AI System content is promoted and the old folder is retained source/history.

## Intentionally not included

- No deletion of `AI System/Conspects Repetition/`.
- No edits to `Canvases/-repeat notes`.
- No edits to active chains/schedules/recovery data.
- No `.obsidian` changes.
- No scripts.
