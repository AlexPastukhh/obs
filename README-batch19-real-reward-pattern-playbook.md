# Batch 19 — Real Reward Pattern Playbook

PUT-style package.

## Purpose

Add the Real Reward Pattern Playbook and connect it to point 6 of the Real Reward Work Loop.

This package does not change daily templates, examples, dashboard template, or Work Rails Principles.

## Files

Create:

- `-Planning/Workflows/Real Reward Pattern Playbook.md`

Update:

- `-Planning/Workflows/Real Reward Work Loop Workflow.md`
- `-Planning/Responsibility Map.md`
- `-Planning/Use Case Map.md`

## Key behavior

Point 6 remains an active race step:

`Race yourself on the short distance with D/F/K/P to improve further actions.`

It now uses active score patterns as score-check criteria.

Active point-6 patterns are:

- all Fundamental score patterns;
- Situational patterns marked `Frequency: frequent`.

Non-frequent Situational patterns are used only when the user says the pattern happened, asks to evaluate it, or the current situation clearly matches it.

## Pattern command

`/patterns` shows full templates for active point-6 patterns:

- all Fundamental score patterns;
- Situational patterns marked frequent.

`/pattern <name>` shows one selected full pattern template.
