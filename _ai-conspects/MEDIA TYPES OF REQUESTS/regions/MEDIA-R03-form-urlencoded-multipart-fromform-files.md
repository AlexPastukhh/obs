## 0.1 Area overview / key ideas / reading quality

What this area is about:
```text
Form request media types: application/x-www-form-urlencoded, multipart/form-data, [FromForm], form fields, file uploads/IFormFile, mixed JSON+file forms, boundaries, and browser/Postman/client submissions.
```

Key ideas:

- application/x-www-form-urlencoded is key/value form data, good for simple forms without files.
- multipart/form-data is required for files and mixed form parts.
- [FromForm] tells ASP.NET Core to bind from form fields/files rather than JSON body.
- IFormFile is the common ASP.NET Core abstraction for uploaded files in multipart/form-data.
- Each multipart part can have its own headers, Content-Disposition name, filename, and optional Content-Type.
- The multipart boundary is generated by the HTTP client and included in the Content-Type header.
- Sending JSON metadata plus files usually means either JSON string field inside multipart or explicit per-part content handling.
