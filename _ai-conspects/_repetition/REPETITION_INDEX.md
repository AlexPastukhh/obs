2. keep `Source status` separate from `Learning state`;
3. set `Recall` from pre-source active recall;
4. set `Next review` and `Next type / scope` from current session evidence;
5. count/link questions from `QUESTIONS_BACKLOG.md`;
6. point `History` to the conspect's lazily created `REPETITION.md`.
