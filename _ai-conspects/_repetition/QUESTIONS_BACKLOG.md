# Questions Backlog

Status: active question registry
Scope: questions discovered while recalling or checking conspects.

## Rules

- Every substantial question receives a stable ID.
- The complete canonical question record lives here.
- Per-conspect `REPETITION.md` entries reference question IDs instead of duplicating the full record.
- A question becomes automatic future-review material only when its status is `INTEGRATED`.
- Resolution should record checked evidence or a source reference when available.

## Statuses

```text
OPEN
RESOLVED
INTEGRATED
DISCARDED
```
