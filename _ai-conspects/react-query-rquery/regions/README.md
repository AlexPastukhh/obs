# Region Transcriptions

This folder is reserved for full source-preserving text transcriptions.

Stage 1 and Stage 2 do not create completed region transcript files. They only prepare maps and inventories.

Future files should follow this pattern:

```text
R01-query-basics.md
R02-staleness-refetch.md
R03-notify-select-side-notes.md
R04-pagination-infinite-query.md
R05-query-composition.md
R06-prefetch-initial-placeholder.md
R07-queryclient-methods.md
R08-offline-network-validation.md
R10-mutations.md
...
```

Each region file should contain:

```text
You are here
Original Excalidraw labels
Screenshot inventory for the region
Exact visible screenshot text
Exact visible screenshot code
Unclear/cut-off markers
Cleaned source notes
Minimal interpretation
Evidence table
Question hooks
```

Actual screenshot transcription starts in Stage 3.
