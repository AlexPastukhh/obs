## 0.1 Area overview / key ideas / reading quality

What this area is about:
```text
JSON/raw-body and ASP.NET request binding: [FromBody], input formatter selection, application/octet-stream custom handling, Stream/byte[] body reads, boundaries, and when MVC returns 415.
```

Key ideas:

- ASP.NET Core input formatters are the layer that interpret request bodies for [FromBody] model binding.
- application/json is handled by JSON input formatters; application/octet-stream often needs raw Request.Body reading or a custom formatter.
- If you read Request.Body yourself, you bypass some model-binding media-type validation.
- A [FromBody] Stream can express raw request-body reading, but direct Request.Body access is often clearer.
- [FromBody] byte[] means the whole body is buffered in memory; use it only for small uploads.
- multipart boundary is generated by the client and separates parts in multipart/form-data.
- 415 Unsupported Media Type is usually about no input formatter/model binder matching the Content-Type and action parameter shape.
