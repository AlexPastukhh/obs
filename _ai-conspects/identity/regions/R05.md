## Screenshot-backed transcript

This region separates two built-in presentation models.

- The default Identity UI/Razor Class Library provides cookie-focused pages such as login, registration, forgot/reset password and email confirmation. It can be scaffolded when customization is required.
- Identity API endpoints are Minimal-API-oriented endpoints for SPAs/mobile/API clients and can support token or cookie-oriented setups depending on configuration.
- Both rely on the same Identity stores and services; choosing between them is primarily about transport/UI architecture, not a different user database.
