## Screenshot-backed transcript

This region introduces ASP.NET Core Identity as the application membership system rather than Windows authentication.

- Identity manages users, password hashes, roles, user/role claims, login cookies, external logins, tokens, lockout and optional 2FA.
- The default EF Core schema includes `AspNetUsers`, `AspNetRoles`, `AspNetUserRoles`, `AspNetUserClaims`, `AspNetRoleClaims`, `AspNetUserLogins` and `AspNetUserTokens`.
- A minimal setup registers the Identity EF stores, token providers, authorization and authentication middleware, then configures the application cookie paths and expiration behavior.
- Authentication establishes who the user is; authorization decides what that principal may do.
