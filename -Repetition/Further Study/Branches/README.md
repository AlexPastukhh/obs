# Further Study Branches

Status: active branch storage folder.

Purpose: store concrete Further Study Branch notes.

Use this folder when a part of a conspect/topic should be studied deeper later, but should not become an active task or repeat unit automatically.

## Rules

```text
- One durable branch = one note in this folder.
- Branch files must link to the source conspect/topic/repeat material.
- Branch files should include the source section or visual anchor when possible.
- Branch files are not scheduled by default.
- Branch files do not enter repeat chains automatically.
- Register open/promoted/closed branches in ../Further Study Index.md.
```

## Naming

Preferred pattern:

```text
YYYY-MM-DD — short branch name.md
```

Examples:

```text
2026-06-05 — SSE reconnect edge cases.md
2026-06-05 — NDJSON vs JSON array streaming.md
2026-06-07 — Antiforgery token internals.md
```
