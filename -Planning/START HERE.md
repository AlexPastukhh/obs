## Current scope

This system supports:

- keeping a flexible current plan;
- creating date-based day files;
- starting a structured day by date;
- logging work sessions into the date-based day file;
- scoring work sessions with D/F/K/P;
- tracking Work Score against 35 / 70 baselines;
- collecting between-session / support facts during the day;
- calculating Support Score at day close / next morning;
- checking course alignment;
- keeping deferred tasks, ideas, and open scenarios without creating extra files;
- showing mnemonic + compact planning state output by default;
- showing full Dashboard Core only on explicit dashboard request;
- using examples as reference outputs for expected formatting.

Do not create extra files unless the user explicitly asks or [[Responsibility Map]] says the new file has a distinct durable responsibility.

AI must not infer current day automatically. User provides the date or establishes an active conversation day date.
