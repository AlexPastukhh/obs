# Planning System Overview

Status: active overview.

## Purpose

`-Planning` helps manage:

- current plans and direction;
- day planning;
- session goals;
- session logs;
- session scoring;
- course alignment;
- work rails;
- deferred tasks and future system ideas.

## Core model

Current Plan State = flexible current plans, focus, tasks, rough schedule, background recovery goal, and important-but-not-now items.

Today State = structured active day dashboard.

Session Log = factual history of sessions, events, and day summaries.

Work Rails Principles = context and rules for D/F/K/P scoring, course alignment, course violations, recovery/NDU, and staying on rails.

Deferred and Ideas Notes = deferred tasks, open scenarios, dangerous scenarios, future workflow ideas, and unstable system notes.

## Main workflow

Current plan -> Today state -> Session -> Log -> Adjust.

## Main constraint

This system is not a complete task map.

It should stay focused on:

- current plan;
- today;
- next session;
- factual logs;
- deferred notes for unstable or future things.

## Scoring model

Sessions are scored with D/F/K/P:

- D = Done / useful work done;
- F = Focus / self-management;
- K = Kurs / relation to current course;
- P = Польза / useful value left.

The score is a practical approximation, not objective truth.
