# Planning System Overview

Status: active overview.

## Purpose

`-Planning` helps manage:

- current plans and direction;
- day planning;
- session goals;
- session logs;
- session scoring;
- course alignment;
- work rails.

## Core model

Current Plan State = flexible current plans, focus, tasks, rough schedule, and important-but-not-now items.

Today State = structured active day dashboard.

Session Log = factual history of sessions, events, and day summaries.

Work Rails Principles = context and rules for scoring, course alignment, course violations, and staying on rails.

Planning Ideas Notes = unstable ideas that should not become files yet.

## Main workflow

Current plan -> Today state -> Session -> Log -> Adjust.

## Main constraint

This system is not a complete task map.

It should stay focused on:

- current plan;
- today;
- next session;
- factual logs.
