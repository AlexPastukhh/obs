# Session Log

Status: legacy / optional index.

Detailed sessions and day summaries now live in date-based day files:

`Days/YYYY/YYYY-MM-DD.md`

Use:

- `Workflows/Use Day File Workflow.md`
- `Workflows/Log Session Workflow.md`
- `Workflows/End Day Workflow.md`

Do not write detailed session history here by default.

This file may later become an index of day files, but it is not the source of truth for day sessions.
