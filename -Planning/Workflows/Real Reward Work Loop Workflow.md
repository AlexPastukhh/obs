# Real Reward Work Loop Workflow

Status: active workflow.

Purpose: turn work from empty effort / stimulation chase into real reward-directed action.

This workflow owns the user's core work loop:

Real reward -> separate from empty stimulation/chemistry -> attach needed stimulation -> handle chemistry/stimulation -> promise when needed -> short-distance D/F/K/P race with active score patterns -> log session.

Emoji notation owner:

`Emoji Notation Map.md`

## Core formula

Реальное удовольствие делает потраченное время не пустой тратой.

Пустые стимулы и химикаты могут притворяться наградой.

Химию чаще надо осознать и дать догореть.

Стимулы чаще надо перенаправить на нужный результат.

Короткая гонка по D/F/K/P превращает энергию в полезное действие и тренирует будущие действия.

## Core loop

1. Find real reward.

   Ask:

   - What real pleasure / relief / control / life improvement makes this time not empty?
   - What would I be glad to have already received?
   - What real good thing would make this action feel worth the time after the fact?

2. Separate real reward from empty stimulation / chemistry.

   Ask:

   - What is real fun / real reward?
   - What is only stimulation?
   - What is chemistry / noise / current pull?
   - What stimulation is competing with real good things?
   - What is only chemistry pretending to be danger, boredom, safety, or relief?

   Principle:

   - Real reward leaves the user in a better real position.
   - Empty stimulation can feel rewarding but leave no useful value.
   - Chemistry can sound like "I want / I do not want", but it is not automatically authority.

3. Attach needed stimulation to the real result.

   Do not try to remove all stimulation.

   Do not feed wrong stimulation.

   Redirect stimulation toward:

   - visible progress;
   - timer;
   - score;
   - short-distance race;
   - self-competition;
   - D/F/K/P.

   Needed stimulation should help the target become more attractive, immediate, and game-like.

   Stimulation should become fuel for the target, not a replacement for real reward.

4. Handle chemistry and stimulation.

   Chemistry handling:

   If chemistry is just resistance/noise:

   - notice it;
   - name it;
   - do not argue with it;
   - do not feed it;
   - wait until it burns out.

   If useful chemistry appears after action:

   - start the short segment first;
   - let the effect appear after action.

   Stimulation handling:

   If stimulation pulls toward empty / wrong direction:

   - do not feed the wrong stimulus;
   - do not provoke more stimulation;
   - do not open extra branches that make the pull stronger;
   - do not let stimulation become the fake reward.

   Redirect stimulation toward the real result:

   - visible progress;
   - timer;
   - visible score;
   - short-distance race;
   - self-competition;
   - D/F/K/P.

   Core distinction:

   - Chemistry is usually noticed, named, not fed, and allowed to burn out.
   - Stimulation is usually redirected toward needed stimuli and the target.

5. Create or refresh promise when needed.

   Use Active Promises only when current chemistry/stimulation conflicts with the analytical prediction and there is enough material.

   Required material:

   - current feeling / pull / lack of pull;
   - target or Desired;
   - analytical prediction;
   - false promise / drift lie;
   - short-distance segment.

   Promise structure:

   - 🧪 Сейчас чувствую / тянет;
   - 📐 Аналитически выведено;
   - 🧵📜 Пришить как истину;
   - 🌑 Не покупать;
   - 🏁 Отрезок.

   Do not create promises by default.

   A promise is used when it must replace current chemistry as the source of truth.

6. Race yourself on the short distance with D/F/K/P to improve further actions.

   Use `📊Скор -> Boost`.

   Use the short-distance race to beat the drifting / weaker / past version of yourself.

   This race should improve:

   - ✅D: useful work actually done;
   - ⚡F: self-management, tempo, target control;
   - 🛤️K: relation to current course / Desired / nearest goals;
   - 💎P: value left after the session;
   - 🧲 future inertia: what this action trains and makes more likely next.

   The race is not only “move faster”.

   It is:

   Produce better D/F/K/P than drift would have produced,
   and train better future actions.

   Use active score patterns as score-check criteria.

   Active point-6 patterns are:

   - all Fundamental score patterns;
   - Situational patterns marked `Frequency: frequent`.

   Non-frequent Situational patterns are used only when the user says the pattern happened, asks to evaluate it, or the current situation clearly matches it.

   Affects F:

   - ⏱️🚂🛤️➡️🎯 Session frame / visible target;
   - 🧲⚡🧪➡️🎯 Targeted stimuli / chemistry only;
   - 🧩🪜⚠️➡️🧲⚡ Complex multi-level problem -> easy stimulation.

   Affects K:

   - 🛤️🌅➡️🎯 Course / Desired connection;

   - 🚂🛤️⚠️🎯 Automatic rails but Result forgotten.

   For full pattern templates, use:

7. Log finished session.

   After the segment:

   - log D/F/K/P;
   - log points;
   - log Progress Signal;
   - update Finished Sessions;
   - decide the next short segment only if needed.

## When to use this workflow

Use this workflow when the user says or means:

- this feels like empty time;
- I am chasing empty stimulation;
- I want the wrong thing;
- I do not feel pull toward useful work;
- I need to make work feel real / rewarding;
- I need to redirect stimulation;
- I need to convert current energy into D/F/K/P;
- I am losing the difference between real reward and chemistry.
