# Start Day Workflow

Status: active workflow.

## Uses

- `Current Plan State.md`
- `Today State.md`
- `Templates/Today State Template.md`

## Steps

1. Read current plan.
2. Choose today’s main goal.
3. Set minimum / good / strong.
4. Set session target.
5. Set current session goal.
6. Set next action.
7. Update `Today State.md`.

## Output

Updated `Today State.md`.
